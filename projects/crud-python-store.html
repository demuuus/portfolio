Store Discount Management System

Overview

A command-line application in pure Python for managing promotions at a minimarket. Owners can create and maintain discount events, and cashiers can apply them during a customer purchase, with the system checking every rule before a discount goes through.

Problem

Minimarkets run several kinds of promotions at once, each with its own period and conditions. Tracking them by hand makes it easy to apply an expired voucher, give a discount the purchase does not qualify for, or let stock records drift from what was actually sold.

Features

  • Create: add promotions with a name, type, start and end date, and discount value
  • Read: list or search promotions and products by keyword
  • Update: edit any field of an existing promotion
  • Delete: remove promotions with a confirmation step
  • Transactions: process a purchase, apply a voucher, and update stock automatically

Promotion Types

  • Percentage: a 1–20% discount, valid on purchases of at least 5 items
  • Buy 2 Get 1: free items on an even quantity, up to 6 items per purchase
  • Fixed: a set Rupiah amount off per item, up to 4 items, and never below a total of Rp0

How It Works

Data is held in memory as lists of dictionaries, so the program runs with no database or external packages. At checkout, the cashier picks a product and quantity, which is checked against available stock. If the customer has a voucher, the system looks up the promotion, confirms it is active for today's date, checks the quantity rules for its type, and asks for confirmation before calculating the final price and deducting stock.

Every input is validated in a loop until it is correct: promotion names accept only letters, numbers, and basic punctuation, dates must follow DD-MM-YYYY with the end date on or after the start date, and numeric fields reject non-numbers and out-of-range values with a clear message.

What I Learned

This project was a foundation in writing a complete program from scratch: breaking a business process into small functions, modelling data with Python's built-in structures, and designing a menu flow that users can navigate without getting stuck. Above all, it taught me to treat input validation and business rules as core features rather than afterthoughts.
